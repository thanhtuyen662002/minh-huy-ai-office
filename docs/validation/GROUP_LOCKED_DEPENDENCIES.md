# Group dependencies inside the owned note transaction

Issue278 / Draft288. The source and brain readers now share their existing exact metadata/cipher dependency reads between public read-only transactions and internal fixed SQL checks. Public key resolution, original source validation, bounded selection, final permission-before-claim ordering and witness-only read expiry behavior remain unchanged.

Internal `RequireUnchangedLockedAsync` accepts only the reader's sealed context. It requires a current SQL Server Serializable transaction, savepoint support and a clean EF tracker; SQL Server MARS cannot supply savepoint support. It acquires the existing source lock through fresh claim inspection, compares every selected dependency with the original context and returns a final typed Current/Expired verdict. The source check includes the exact allocated cutoff and coverage-gap state. The brain check includes exact business head, revision/cipher, evidence/current source and glossary policy, with the work permission proof preceding its final claim verdict. No key is resolved and no private text is decrypted in these checks.

An Expired verdict contains no allocation/read capability and performs no retirement, savepoint, rollback or commit. The owned effect consumer must acquire the source lock before its effect savepoint, stage and flush only its fixed known effects, inspect all dependencies again and, on expiry, roll back every flushed effect and detach its own entries before calling the existing metadata-only retirement operation and committing the witness. Unsupported savepoints/MARS must refuse before effects. A successful check is an instantaneous dependency result, not authority for a later transaction or provider release. There is no arbitrary effect callback wrapper.

175 relevant source/brain/proposal/codec controls pass, including four new actual entry refusals for non-SQL and SQL-without-transaction at both current and expired clock values. They verify no key read, effect or expiry witness. These are cold tests. Native invocation of the new internal checks, source-lock-before-savepoint retention, rollback of already flushed effects and MARS refusal in the first production consumer are still unqualified. No effect store, automatic DI, model or completed raw ledger is shipped by this refactor.
