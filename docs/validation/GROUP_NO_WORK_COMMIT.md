Initial fresh permission/claim/source/brain checks acquire the shared transaction-owned source lock before creating the effect savepoint. Other failures dispose the whole transaction and detach staged entries. No arbitrary callback can add effects. Caller cancellation remains cancellation; private errors are fixed without an inner diagnostic. A clock rollback below the effect timestamp refuses before the final claim verdict.
