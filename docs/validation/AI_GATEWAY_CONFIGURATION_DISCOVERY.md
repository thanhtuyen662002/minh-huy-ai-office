# Existing AI Gateway configuration discovery

Read-only inspection on2026-10-10. No provider request, secret mutation or customer activation was performed. Only repository configuration loaders, launch/deployment scripts and their exact default references were checked. Secret values were neither printed nor persisted.

## Actual loader and delivery

- `src/Agent.Worker/Program.cs` creates the existing primary/backup Responses adapters and `OrderedFailoverAiGateway`. `OpenAiCompatibleResponsesOptions.FromEnvironment` reads process variables directly. A missing primary keeps the bounded connectivity-probe executor; a partial provider or backup without primary refuses startup.
- Required primary variables: `AIOFFICE_AI_PRIMARY_BASE_URL`, `AIOFFICE_AI_PRIMARY_MODEL`, `AIOFFICE_AI_PRIMARY_AUTHORIZATION`. Authorization is the complete secret HTTP header value. Optional `AIOFFICE_AI_PRIMARY_PROVIDER_ID` defaults to `openai-direct`.
- Optional backup uses the same four suffixes under `AIOFFICE_AI_BACKUP`. Legacy `AIOFFICE_AI_BASE_URL`, `AIOFFICE_AI_MODEL`, `AIOFFICE_AI_AUTHORIZATION`, `AIOFFICE_AI_PROVIDER_ID` remain primary aliases. Explicit primary values take precedence.
- `infra/deploy-backend.ps1` defaults to the ignored `.env.production`; `-EnvironmentFile` selects an operator-protected file. `compose.production.yaml` maps these variables only to the server worker. The non-secret template is `.env.production.example`. An approved service/container secret injector can supply the same worker process variables. No Vault/cloud AI-secret adapter is registered in this worker; no independent client or configuration is needed.
- `infra/start-local.ps1` defaults to `%LOCALAPPDATA%/MinhHuyAIoffice/LocalRuntime/local.env`, generated by `initialize-local-config.ps1`. That generator and `compose.local.yaml` currently do not forward AI-provider variables; manually adding keys to generated local.env is not a supported retained provider configuration.
- The user-supplied ERP file `D:/Config/appsettings.Private.json` is not referenced by the worker AI loader or these launch scripts. An appsettings AI section or .NET user-secret does not feed this direct environment reader automatically.
