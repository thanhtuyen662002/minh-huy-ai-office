# Closed host attention payload preparation

Issue278 / Draft288. `group-brain-host-attention-v1` distinguishes host observations from AI interpretations and IT-confirmed state. The closed private format contains only its version, `interpretation_role=host_metadata_attention`, one finite reason, a coverage-gap observation, nullable quarantine policy version and1–10 original source message/revision references. It contains no source text/quote, summary, model response, private exception, external sender/account ID, credential match, business commitment, destination or scope authority.

Reasons are unsupported_media, secret_quarantine and extraction_failed. Quarantine requires the exact current versioned known-form policy; the other reasons require a null policy. IDs must be canonical nonzero GUIDs, revisions positive integers, and each source message occurs once. Unsupported media and failed extraction do not claim the content was understood. A gap observation does not claim complete raw-batch coverage. The fixed downstream host consumer must establish current source dispositions and bounded retry exhaustion; this format primitive cannot establish those facts or authorize persistence.

Encoding bounds actual reference enumeration to11 before accepting at most10; it does not trust a caller's reported list count. Decoding reuses the existing strict UTF8/64,000-byte/closed duplicate-name/known-secret JSON boundary. Unknown or missing fields, extra quotes/authority, invalid roles/reasons/policies, malformed IDs/revisions and overflow refuse with the same fixed private error and no inner diagnostics. Decoded collections are immutable. Existing AI/glossary decoders refuse host payloads; their established formats remain unchanged.

This preparation adds no SQL rows, migration, key resolution, provider call, DI activation or report. The original request revision migration admits only AI/IT origin/verification combinations. The separate prepared versioned expand migration and reader support an explicit HostAttention/HostObserved combination before a fixed host store can write it (see GROUP_HOST_ATTENTION_READER.md); it must never label host metadata as a source-backed AI interpretation or IT confirmation. Preserve all existing AI/IT combinations and least-privilege immutable evidence. New writes stay disabled until readers understand the added origin and native rights/effect/replay proof passes.

Known text in a partial listener gap must still produce evidence-backed notes with honest incomplete-coverage metadata. A future gap-only receipt/attention must not silently consume known actionable text or duplicate full source dispositions. Media captions may support separately validated interpretations while unknown media is reported honestly. Pure recalls/obsolete revisions and empty text retain their own terminal metadata outcomes; this codec does not manufacture an AI no-work verdict for them. Zero-message gaps require their own durable identity, rather than an invented message ID in this source-reference format.

Independent review of frozen ccb95b6 reproduced a collection fast-path defect: LINQ Take/ToArray can trust an IList caller reporting Count=1 although its enumerator returns11 references, silently dropping ten. Encoding now directly enumerates at most the eleventh actual item, rejects overflow immediately and disposes the enumerator. It does not read caller Count or indexers. Permanent controls cover empty/one/ten/eleven actual items under the false advertised size, and an unbounded sequence that must stop at11 and dispose.
